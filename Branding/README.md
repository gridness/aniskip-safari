# Anime365 assets

Original images downloaded from Anime365:

- `anime365-logo.png`: https://smotret-anime.com/images/logo.png?2 (website header logo, 240 × 70).
- `anime365.png`: https://smotret-anime.com/android-chrome-512x512.png (published app icon, 512 × 512).

The header logo is copied unchanged into the app and popup. The published icon is resampled for the required platform sizes by `scripts/generate-artwork.py` (requires Pillow). No replacement artwork is generated.

The UI accent is **#1b5e20**, the main green in the header logo and the site's published theme color.
